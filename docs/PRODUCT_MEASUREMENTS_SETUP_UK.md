# Підключення збереження замірів

Код редактора готовий у тестовій гілці `codex/prelaunch-mobile-polish`. Для запису в базу адміністратор проєкту має один раз виконати підготовлений SQL.

1. Відкрийте [SQL Editor проєкту Vintage Hedonista](https://supabase.com/dashboard/project/yffwjgwwkapdrpwyjwfp/sql/new).
2. Скопіюйте **весь вміст** [міграції замірів](../supabase/migrations/202610290001_product_measurements.sql) у новий SQL-запит та натисніть **Run**.
3. Після успішного виконання перезавантажте тестову адмінку. Відкрийте існуючий товар, змініть замір і натисніть **Зберегти**. Має з’явитися повідомлення «Заміри збережено в базі».
4. Вийдіть зі сторінки товару та відкрийте його повторно. Збережена назва й значення мають залишитися. У звичайній картці товару тестового сайту вони будуть у розділі **ЗАМІРИ**.

SQL додає окреме поле, перевірку даних і запис замірів лише для адміністратора. Він не переносить, не очищує й не перераховує старі значення. Наявні ціни, описи, фотографії та правила доступу до товарів залишаються без змін. Повторний запуск цього SQL також перевірений.

У тестовій адмінці ця кнопка записує **тільки заміри**. Інші змінені поля товару залишаються незбереженими; редактор показує їхній стан. Основний сайт продовжує працювати зі своїм поточним кодом до окремого перенесення гілки.

Локальні чернетки автоматично не публікуються: вони відновлюються у формі, а запис у базу відбувається після натискання «Зберегти». Якщо SQL ще не виконано або сервер відхилив запис, чернетка залишається у браузері.
