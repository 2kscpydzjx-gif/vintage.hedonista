# Каталог і типографіка головної

Три правки готуються в тестовій гілці разом із виправленням капсул. Основний сайт і дані Supabase не змінюються.

- Прибрано видимий disclosure «Переглянути всі товари колекції». Статичні посилання залишено в noscript як корисний резервний каталог без JavaScript. Генератор використовує той самий шаблон; повторний запуск не повертає напис і не створює вкладених noscript. Стандартний каталог, фільтри та «Показати ще» збережені.
- Заголовок Slow Fashion використовує Prata Regular 400 для латиниці й української. До змін CDP підтвердив суміш Bodoni Moda та Liberation Serif: Bodoni не покривав українські гліфи. Ручні NBSP-відступи та br прибираються лише з відображення заголовка й підзаголовка цього блока; записана CMS-ревізія не переписується. При повторному рендері редактора очищення застосовується знову. Наявну кнопку «Про нас» прибрано із джерела блока; кнопка Hero лишається.
- Hero зберігає поточний Prata Regular. Збільшено відстань між літерами/словами й рядками, вимкнено лігатури та синтетичні начертання. Початковий огляд підтвердив Prata для всього змішаного заголовка. Кадрування, фото й анімації не змінювалися.

До втрати локального середовища оглянуто чинний опублікований контент і шрифти через read-only proxy на 1366/820/390 px; робочих записів немає. Подальші правки внесено через GitHub Git Data API в ту саму тестову гілку. Остаточний вигляд локально не оглянуто через недоступність середовища.

Перевірки в CI: tests/home-presentation.cjs (320/390/820/1366 px, обрізання, Prata/400, інтервали Hero, видалення тільки editorial CTA, повторне застосування CMS без запису ревізії, каталог з/без JS); tests/seo-editorial.mjs (екранування посилань та ідемпотентна генерація). Повні існуючі браузерні набори й SEO-аудити також запускаються. CSS/JS головної та site.js каталогу мають версію кешу 291.
