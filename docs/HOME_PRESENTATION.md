# Каталог і типографіка головної

Три правки готуються в тестовій гілці разом із виправленням капсул. Основний сайт і дані Supabase не змінюються.

- Прибрано видимий disclosure «Переглянути всі товари колекції». Статичні посилання залишено в noscript як корисний резервний каталог без JavaScript. Генератор використовує той самий шаблон; повторний запуск не повертає напис і не створює вкладених noscript. Стандартний каталог, фільтри та «Показати ще» збережені.
- Заголовок Slow Fashion використовує Prata Regular 400 для латиниці й української. До змін CDP підтвердив суміш Bodoni Moda та Liberation Serif: Bodoni не покривав українські гліфи. Ручні NBSP-відступи та br прибираються лише з відображення заголовка й підзаголовка цього блока; записана CMS-ревізія не переписується. При повторному рендері редактора очищення застосовується знову. Наявну кнопку «Про нас» прибрано із джерела блока; кнопка Hero лишається.
- Hero використовує те саме накреслення Prata Regular із локально вирівняними контурами великих літер поточного заголовка. У джерелі Prata округлі/загострені літери виходили за cap height/baseline на 10–20 одиниць із 1000: наприклад, A yMax=820, H yMax=800, O yMin=-20. Вирівняно ці оптичні виступи до cap height=800 та baseline=0; нижній елемент Ц збережений. Горизонтальні контури, ширини, kerning і метрики рядка не змінені. Попередні додані letter/word spacing, line-height=1.24 і text-wrap:balance прибрано; повернуто початкові переноси. Жодних вставлених br або обгорток окремих літер.

Локальний файл `assets/fonts/prata/hero-aligned.woff2` (близько 24 KB) застосовується лише до Hero; preload забезпечує раннє завантаження. Вихідний Prata включено в `scripts/font-sources/Prata-Regular.ttf`, SIL OFL та опис модифікації — в `assets/fonts/prata/`. Відтворення: `python3 scripts/align-prata.py` після встановлення `fonttools[woff]`. Вихідний TTF SHA256: `6bab61b8b8df3f5a24df69c742f6495060b36aec686f37e534ff91a3bffe40ad`.

Після відновлення середовища остаточний вигляд оглянуто в Chromium з реальними публічними фото, збереженою CMS-ревізією та шрифтами на 1366/820/390 px через read-only proxy; записів у Supabase немає. CDP підтвердив завантаження локального шрифту. Висота Hero-заголовка, початкові міжлітерні/міжрядкові інтервали збігаються з версією до правок; на 1366 px рядки знову «VINTAGE HEDONISTA —» / «МИСТЕЦТВО БУТИ» / «СОБОЮ». Фото, кадрування та анімації не змінювалися. Фізичні Safari/iOS не перевірялися.

`tests/home-presentation.cjs` перевіряє 320/390/820/1366 px, збереження координат кожної літери та переносів проти оригінального Prata, однакові верхні/нижні межі великих літер через Canvas (із винятком нижнього елемента Ц), відсутність обрізання, видалення тільки editorial CTA, повторне застосування CMS без запису ревізії, каталог з/без JS. Додатково перевірено responsive-layouts, cms-entry-experience та SEO-шаблони. CSS головної має версію кешу 292, JS головної та каталогу — 291.
