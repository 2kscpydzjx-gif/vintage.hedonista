# Аналітика Vintazhka

GA4: `G-15N51M35Y2`, вебпотік `16249083327`.

Тег додається під час збірки лише для основного домену. Рантайм додатково перевіряє `vintazhka.com.ua`, виключає iframe, кабінет, адмінку й URL з параметрами підтвердження входу. Preview, pages.dev, Vercel та старий GitHub Pages не надсилають статистику.

Google завантажується після «Дозволити» в панелі аналітичних cookie. «Відхилити» залишає магазин працездатним. Вибір зберігається 180 днів; змінити його можна кнопкою «Налаштування cookie» у футері. Рекламні сигнали й персоналізація вимкнені. Блокувальники реклами та відмова означають, що частина відвідувань не буде у звіті.

Вимкніть «Улучшенная статистика» / Enhanced measurement у вебпотоці: події надсилає власний рантайм. Автоматичне відстеження форм, пошуку та зовнішніх посилань не потрібне. Власні події не містять імен покупців, контактів, адрес, коментарів, профілів, ID замовлень, URL-фрагментів та довільних параметрів URL. Referrer обмежено origin. UTM-параметри наразі також вилучаються; детальна атрибуція рекламних кампаній — окреме майбутнє налаштування.

| Подія | Коли надсилається |
|---|---|
| `page_view` | Один раз на сторінці після дозволу |
| `view_item` | Після успішного завантаження конкретного товару |
| `add_to_cart` | Після додавання нових речей; повторне натискання не додає подію |
| `remove_from_cart` | Коли покупець сам прибирає річ із кошика |
| `begin_checkout` | Після відкриття форми «Купити» або непорожнього checkout; повторний рендер того самого набору не дублює подію |
| `order_placed` | Тільки після успішної відповіді сервера з ID створених замовлень; ідентифікатори потрібні тільки для локального усунення дублювань і не передаються Google |

Оформлення замовлення не підтверджує оплату. Подія `purchase` і звіт про сплачену виручку не вмикаються. Для замовлення капсули враховується комплектна ціна. До дозволу події дій із кошиком і замовлень не накопичуються заднім числом; можна надіслати поточний контекст товару/checkout після дозволу.

## Перевірка після публікації

1. Вимкнути Enhanced measurement у потоці.
2. Відкрити основний сайт у новому вікні без блокувальника для цього сайту, дозволити аналітичні cookie.
3. У GA4 відкрити «Отчеты → В реальном времени», перейти в каталог, переглянути товар, додати й прибрати його з кошика.
4. Перевірити `page_view`, `view_item`, `add_to_cart`, `remove_from_cart`, `begin_checkout`. Не створювати реального замовлення заради перевірки: успіх/відмову RPC покрито ізольованими браузерними тестами.
5. Після появи `order_placed` у GA4 за потреби позначити її ключовою подією. Це кількість оформлень, а не підтверджена оплата.

Дані реального часу зазвичай з'являються за кілька хвилин; стандартні звіти можуть оброблятися 24–48 годин. Локальні тести перехоплюють Google і використовують ізольовані товари та RPC, тому не забруднюють робочу статистику.
