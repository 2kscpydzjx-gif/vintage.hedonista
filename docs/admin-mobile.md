# Мобільна адмінка — тестова гілка

Гілка `codex/prelaunch-mobile-polish`, основа поточної роботи — `7955ca9` після попереднього релізу. Зміни обмежено активною адмінкою, її входом, конструктором і перевірками. Опубліковані сторінки/товари/замовлення та робочий Supabase цими перевірками не змінюються.

## Адміністративна панель

До 1199 px навігація відкривається як бокове меню з фоном, доступною кнопкою закриття, Escape/Tab, блокуванням фону й поверненням фокуса. Перехід на ширший екран прибирає блокування. Кнопки мають сенсорну висоту від 44 px; поля — шрифт 16 px. Критичні розміри винесені в CSS layer з important, щоб їх не перекривали старі правила конкретних розділів.

Таблиці до 767 px показують усі клітинки картками, включно з редагуванням і впорядкуванням; заголовки й ролі таблиць зберігаються. На планшеті таблиці вкладаються у відведену ширину. Форми, медіа, галерея товару та інструменти тексту переносяться у доступні колонки. Фото у редакторі статті показуються ширшими для доступу до інструментів; збережені пропорції й атрибути фото не переписуються.

Нижня панель збереження товару/статті/капсули/стилю викликає існуючу кнопку, повторює її disabled-стан і не змінює серверний контракт. Діалоги замовлення, медіатеки, клієнта й категорії мають доступне закриття та керування фокусом. Мобільний вхід отримав форму з labels/autocomplete, Enter, блокуванням повторного запиту й зрозумілими сталими помилками; перевірка `is_admin` збережена.

## Конструктор

Вузький екран має три панелі: блоки, перегляд, налаштування. Iframe і поля не пересоздаються при перемиканні. Перегляд зберігає геометрію навіть коли прихований: використано clipping, оскільки канонічний runtime сам задає iframe `visibility:visible`. Прихований iframe недоступний для фокуса та жестів. Початковий пристрій перегляду — телефон або планшет залежно від ширини; користувач може вибрати інший.

Доступні всі вкладки, збереження, публікація відповідно до чинних прав/обмежень preview, undo/redo, вибір сторінки, налаштування фото/кнопок і SEO. SEO на вузькому екрані має власне вікно зі стало доступним закриттям. Оригінальний просторий режим повертається на ширині від 1200 px.

`admin/viewport.js` використовує VisualViewport, щоб панель дій і діалоги вкладалися у видиму область при відкритті клавіатури. Під час pinch zoom автоматичне підлаштування вимикається. На браузерах без API залишаються стандартні viewport-одиниці.

## Перевірки

- `tests/admin-mobile.cjs`: 13 основних розділів на 320/360/390/430/600/768/820/1024/1180/1440 px, розгорнуті секції, доступні кнопки/поля, галерея, меню/обертання, замовлення, медіатека, профіль і категорії, сценарій віртуальної клавіатури та відсутність циклу observer.
- `tests/admin-login-mobile.cjs`: мобільний вхід, Enter, помилки, повторне натискання, відмова не-адміністратору, успішний перехід. Запити авторизації підставні.
- `tests/cms-mobile.cjs`: вісім ширин, усі вкладки з розгорнутими деталями, текст/фото/кадрування через перемикання панелей, збереження/F5, desktop round-trip, сенсорне кадрування через Chromium touch events і SEO при короткому видимому вікні. Опубліковані записи не змінюються.

Нові набори включені в CI разом з наявними 31 наборами; загалом 34 браузерні набори. Скріншоти ізольованої адмінки додаються як артефакт `admin-mobile-screenshots`. CI перевіряє готові файли `dist`.

Це перевірки Chromium з емульованими сенсорними екранами, а не фізичних iPhone/iPad. Перевірка Safari/нативної клавіатури на реальному пристрої залишається потрібною. Preview все ще використовує спільний Supabase: ручне збереження через справжню авторизовану адмінку може змінити робочі дані. Автоматичні набори використовують fixture та не звертаються до робочого backend.
