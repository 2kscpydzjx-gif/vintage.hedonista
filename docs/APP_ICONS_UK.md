# Іконки Vintazhka для браузера й головного екрана

Використано PNG власника:
https://yffwjgwwkapdrpwyjwfp.supabase.co/storage/v1/object/public/vintage-media/media-library/1793617687372-tlq36-IMG_6193.PNG

Оригінал 1254×1254px, SHA-256 `516384204da98564af281095ba80eb767a978b99c2aa45ee04ea057ba9e94df1`, залишається в медіатеці. Технічні експорти містять те саме зображення без перемальовування:

- `favicon.ico`: PNG-кадри 16/32/48px; окремі PNG 16/32px для вкладок.
- Apple touch icon 180px, з непрозорим темно-коричневим фоном; також є стандартний `/apple-touch-icon.png`.
- Android/web app PNG 192/512px. Непрозора версія 512px також підтримує системну маску Android; центральний манекен збережений.

`site.webmanifest` відкриває магазин із назвою **Vintazhka** та ідентифікатором `/`. `admin/site.webmanifest` має назву **Vintazhka Admin**, ідентифікатор і область `/admin/`, стартує зі сторінки входу. Тому обидва ярлики можна додати окремо. Налаштування входу й робочі дані не змінені. Service worker та офлайн-кеш приватних сторінок не додаються.

Посилання й Apple-метадані є у вихідних HTML магазину/адмінки; збірка також додає їх до всіх старих SEO-сторінок. Генератор SEO використовує той самий helper. Версія в URL іконок допомагає оновити попередній favicon.

Для наступного оновлення: завантажити оригінальний PNG та запустити `node scripts/generate-app-icons.cjs /path/to/original.png`. Скрипт лише змінює технічні розміри через браузерний canvas і формує ICO; додаткові пакети не потрібні.

Наступний тестовий варіант використовує окремий знак V для браузера (див. `FOOTER_PRIVACY_REVIEW_UK.md`). Прапорець `--browser-only` оновлює лише favicon, зберігаючи попередні Apple/Android-іконки.

Перевірки: склад публічної збірки, коректність розмірів PNG/ICO, непрозорість домашніх іконок, окремі ідентифікатори/стартові адреси, правильні шляхи на вкладених SEO-сторінках, завантаження в мобільному браузері та відсутність записів у базу.

Телефон може зберегти іконку вже створеного ярлика. Щоб отримати нову, видалити старий ярлик і додати сторінку на головний екран знову.
