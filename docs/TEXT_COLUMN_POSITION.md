# Положення текстових колонок

У тестовій гілці розширено спільний редактор наявних і нових блоків. У «Макет → Композиція тексту» після вибору «Заголовок ліворуч» або «Заголовок праворуч» доступні окремі панелі заголовка й основного тексту:

- вирівнювання ліворуч / по центру / праворуч або успадкування наявного оформлення;
- положення вгорі / посередині / внизу або успадкування макета;
- внутрішні відступи зверху, знизу, ліворуч і праворуч (0–120 px);
- спільний проміжок між колонками (0–120 px);
- скидання положення лише однієї колонки без втрати тексту, фото чи типографіки.

Дані зберігаються в наявному `design`: `headingAlign`, `bodyAlign`, `headingPosition`, `bodyPosition`, `headingInsetTop/Right/Bottom/Left`, `bodyInsetTop/Right/Bottom/Left`, `textColumnGap`. Нові поля необов’язкові. Без них збережені композиції виглядають як раніше. Схему БД та CMS-ревізії не мігровано.

Явне вирівнювання колонки застосовується до її текстових клонів і має пріоритет над загальним/польовим вирівнюванням та примусовими стилями Slow Fashion. Вибір «Як у налаштуваннях тексту» або скидання повертає старе оформлення. Шрифт, розмір, колір і насиченість не змінюються. Кнопки зберігають власний редактор положення.

Колонки залишаються в CSS grid, відступи займають місце в потоці. Немає абсолютного позиціювання чи від’ємних зсувів, які спричиняли б накладання на сусідню колонку. Бічні відступи обмежено 20% ширини колонки. На телефоні збережено порядок «заголовок → текст»; бічні відступи обмежено 20 px, верхній/нижній — 28 px. Вертикальне вирівнювання діє в доступній висоті: для автовисоти вона визначається вмістом, для точної висоти використовується вся текстова область. Рядок доданих кнопок зберігає природну висоту.

Спільна модель і fallback-завантажувач мають версію 7; runtime — 169, панель — 210, stylesheet редактора — 5. Посилання в HTML оновлено для уникнення старих моделей із кешу. Запобіжник публікації з `.vercel.app` збережено.

`tests/cms-column-position.cjs` проходить панель → живе прев’ю → ізольоване серверне збереження → F5 → ізольовану публікацію → рендер на 1366/820/390/320 px. Перевіряє обидва напрями колонок, незалежне вирівнювання/відступи, пріоритет над Slow Fashion CSS, перемикання макетів, скидання лише однієї колонки, стабільне прокручування інспектора, незмінність Hero/фото/типографіки, відсутність запису публікації під час редагування, мобільні обмеження й рендер нових блоків. Тест додано до CI поряд із наявними перевірками колонок, кнопок і редактора.

Робочі чернетки/публікації Supabase, замовлення й основний сайт цими правками не змінювалися.

Окремо виконано read-only огляд із реальними публічними фото, шрифтами й поточною ревізією Slow Fashion на 1366/820/390 px для обох напрямів колонок. Нові параметри застосовувалися лише до локального DOM. У шести сценаріях немає JS-помилок, записів або горизонтального переповнення; вигляд оглянуто зі скриншотів. Фізичні Safari/iOS не перевірялися.
